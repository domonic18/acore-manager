### 2.2 目录说明

| 目录 | 用途 | 规范 |
|------|------|------|
| `src/features/` | 功能模块 | 按业务领域垂直拆分（15 个），每个 feature 自包含（api + hooks + components 子集）；**禁止跨 feature import** |
| `src/shared/` | 共享层 | 跨 feature 复用的组件、hooks、工具；新增共享件须 ≥2 个 feature 消费；禁止反向依赖（shared 不引用 feature） |
| `src/pages/` | 页面入口 | 薄壳 ≤ ~100 行，仅组合 feature 组件，不实现业务逻辑；逻辑下沉对应 feature |
| `src/app/` | 应用配置 | 路由、Provider、全局布局 |
| `src/shared/components/ui/` | shadcn/ui 组件 | 通过 CLI 生成，不手动修改内部实现，仅通过 props 和 className 定制外观 |

> 导入路径规范：跨目录用 `@/` 别名，同目录用 `./`，禁止 `../` 上溯。

## 三、核心样式系统

### 3.1 设计原则

- **管理后台优先**：布局参考经典 Admin Dashboard（Sidebar + Header + Content），信息密度高
- **移动端适配**：GM 经常需要在手机/平板上应急操作，关键功能（封禁、查找玩家）必须可在移动端完成
- **暗色主题默认**：默认 dark 模式，与魔兽世界 UI 风格一致，减少夜间操作眼疲劳
- **零自定义 CSS**：优先使用 Tailwind utility classes，仅在必要时使用 CSS 变量

### 3.4 响应式布局策略

管理后台采用 **Sidebar 可折叠** 的响应式布局：

| 断点 | 范围 | 布局策略 |

| 默认 | < 768px | Sidebar 隐藏，通过汉堡菜单展开；内容区全宽；表格横向滚动 |
| `md` | 768px+ | Sidebar 固定 240px 宽度；内容区自适应 |
| `lg` | 1024px+ | Sidebar 展开；内容区宽裕；表格完整展示 |

## 四、API 客户端层

### 4.1 HTTP 客户端封装

```typescript
// src/shared/api/client.ts

const API_BASE_URL = import.meta.env.VITE_API_BASE_URL || '';

function buildUrl(path: string): string {
  const base = API_BASE_URL.replace(/\/$/, '');
  const url = base ? `${base}${path}` : path;
  return url;
}

async function request<T>(path: string, options?: RequestInit): Promise<T> {
  const token = localStorage.getItem('acm_token');
  const url = new URL(buildUrl(path), window.location.origin);

  const response = await fetch(url.toString(), {
    headers: {
      'Content-Type': 'application/json',
      ...(token ? { Authorization: `Bearer ${token}` } : {}),
      ...options?.headers,
    },
    ...options,
  });

  if (response.status === 401) {
    localStorage.removeItem('acm_token');
    window.location.href = '/login';
    throw new Error('Session expired');
  }

  if (!response.ok) {
    throw new Error(`HTTP ${response.status}: ${response.statusText}`);
  }

  const result = await response.json();
  if (!result.success) {
    throw new Error(result.error || 'API request failed');
  }

  return result.data;
}

export const apiClient = {
  get: <T>(path: string) => request<T>(path, { method: 'GET' }),
  post: <T>(path: string, body?: unknown) => request<T>(path, {
    method: 'POST',
    body: body ? JSON.stringify(body) : undefined,
  }),
  patch: <T>(path: string, body?: unknown) => request<T>(path, {
    method: 'PATCH',
    body: body ? JSON.stringify(body) : undefined,
  }),
};
```

### 4.2 端点定义

端点不集中维护：各 feature 在自己的 api 模块内定义端点与响应类型（如 `features/account/api/account.api.ts` 导出 `accountApi` 与 `AccountListItem` 等类型），共享层只提供 `client.ts` 传输封装。这保证 feature 自包含、删除一个 feature 不留悬空引用：

```typescript

  ban: (id: number, data: BanInput) => apiClient.post(`/api/accounts/${id}/ban`, data),
  // ...
};
```

### 5.2 认证状态管理（React Context）

```typescript
// src/shared/hooks/useAuth.ts

import { createContext, useContext, useState, useCallback } from 'react';

interface User {
  id: number;
  username: string;
  gmlevel: number;
}

interface AuthContextType {
  user: User | null;
  isAuthenticated: boolean;
  login: (token: string, user: User) => void;
  logout: () => void;
}

const AuthContext = createContext<AuthContextType | null>(null);

export function AuthProvider({ children }: { children: React.ReactNode }) {
  const [user, setUser] = useState<User | null>(() => {
    const saved = localStorage.getItem('acm_user');
    return saved ? JSON.parse(saved) : null;
  });

  const login = useCallback((token: string, userData: User) => {
    localStorage.setItem('acm_token', token);
    localStorage.setItem('acm_user', JSON.stringify(userData));
    setUser(userData);
  }, []);

  const logout = useCallback(() => {
    localStorage.removeItem('acm_token');
    localStorage.removeItem('acm_user');
    setUser(null);
  }, []);

  return (
    <AuthContext.Provider value={{
      user,
      isAuthenticated: !!user,
      login,
      logout,
    }}>
      {children}
    </AuthContext.Provider>
  );
}

export function useAuth() {
  const context = useContext(AuthContext);
  if (!context) throw new Error('useAuth must be used within AuthProvider');
  return context;
}
```

```typescript
// src/shared/hooks/usePermission.ts

import { useAuth } from './useAuth';

export function usePermission() {
  const { user } = useAuth();

  const hasGmLevel = (minLevel: number): boolean => {
    return (user?.gmlevel ?? 0) >= minLevel;
  };

  const canManageAccounts = () => hasGmLevel(3);
  const canManageCharacters = () => hasGmLevel(2);
  const canViewTransactions = () => hasGmLevel(1);
  const canUseGmTools = () => hasGmLevel(2);
  const canViewAuditLogs = () => hasGmLevel(2);
  const canViewAllAuditLogs = () => hasGmLevel(3);

  return {
    hasGmLevel,
    canManageAccounts,
    canManageCharacters,
    canViewTransactions,
    canUseGmTools,
    canViewAuditLogs,
    canViewAllAuditLogs,
    gmlevel: user?.gmlevel ?? 0,
  };
}
```

```typescript
// src/app/router.tsx

import { createBrowserRouter, Navigate, Outlet } from 'react-router-dom';
import { Suspense, lazy } from 'react';
import { LoadingState } from '@/shared/components/LoadingState';
import { useAuth } from '@/shared/hooks/useAuth';
import { usePermission } from '@/shared/hooks/usePermission';

// 懒加载页面组件
const LoginPage = lazy(() => import('@/pages/LoginPage'));
const DashboardPage = lazy(() => import('@/pages/DashboardPage'));
const AccountListPage = lazy(() => import('@/pages/AccountListPage'));
const AccountDetailPage = lazy(() => import('@/pages/AccountDetailPage'));
const CharacterListPage = lazy(() => import('@/pages/CharacterListPage'));
const CharacterDetailPage = lazy(() => import('@/pages/CharacterDetailPage'));
const TransactionPage = lazy(() => import('@/pages/TransactionPage'));
const GmToolPage = lazy(() => import('@/pages/GmToolPage'));
const AuditLogPage = lazy(() => import('@/pages/AuditLogPage'));

function withSuspense(Component: React.ComponentType) {
  return (
    <Suspense fallback={<LoadingState />}>
      <Component />
    </Suspense>
  );
}

// 登录守卫：已登录则跳转 Dashboard
function GuestGuard() {
  const { isAuthenticated } = useAuth();
  return isAuthenticated ? <Navigate to="/" replace /> : <Outlet />;
}

// 认证守卫：未登录则跳转登录页
function AuthGuard() {
  const { isAuthenticated } = useAuth();
  return isAuthenticated ? <Outlet /> : <Navigate to="/login" replace />;
}

// GM 等级守卫
function GmGuard({ minLevel }: { minLevel: number }) {
  const { hasGmLevel } = usePermission();
  return hasGmLevel(minLevel) ? <Outlet /> : <Navigate to="/" replace />;
}

export const router = createBrowserRouter([
  {
    path: '/login',
    element: <GuestGuard />,
    children: [{ path: '', element: withSuspense(LoginPage) }],
  },
  {
    path: '/',
    element: <AuthGuard />,
    children: [
      { path: '', element: withSuspense(DashboardPage) },
      {
        path: 'accounts',
        element: <GmGuard minLevel={3} />,
        children: [
          { path: '', element: withSuspense(AccountListPage) },
          { path: ':id', element: withSuspense(AccountDetailPage) },
        ],
      },
      {
        path: 'characters',
        children: [
          { path: '', element: withSuspense(CharacterListPage) },
          { path: ':guid', element: withSuspense(CharacterDetailPage) },
        ],
      },
      {
        path: 'transactions',
        element: <GmGuard minLevel={1} />,
        children: [{ path: '', element: withSuspense(TransactionPage) }],
      },
      {
        path: 'gm-tools',
        element: <GmGuard minLevel={2} />,
        children: [{ path: '', element: withSuspense(GmToolPage) }],
      },
      {
        path: 'audit-logs',
        element: <GmGuard minLevel={2} />,
        children: [{ path: '', element: withSuspense(AuditLogPage) }],
      },
    ],
  },
]);
```

## 七、组件开发规范

### 7.1 组件组织原则

| 类型 | 位置 | 说明 |
|------|------|------|
| **页面组件** | `src/pages/` | 路由入口，仅组合 feature 组件 |
| **Feature 组件** | `src/features/X/components/` | 特定业务领域的组件 |
| **共享组件** | `src/shared/components/` | 跨 feature 复用 |
| **shadcn/ui 组件** | `src/shared/components/ui/` | CLI 生成的基础组件 |

### 7.2 通用表格封装（SimpleTable）

列表/详情页的表格统一使用 `src/shared/components/SimpleTable.tsx`：列定义为数据（`columns` 数组），组件内部统一渲染容器（`rounded-lg border` + 横向滚动）、加载/空态行与单元格留白；行操作列在组件函数体内构建 columns，以便闭包捕获 handlers。分页统一走 `PaginationBar`。

```tsx
// src/shared/components/SimpleTable.tsx（接口示意）

export interface SimpleColumn<Row> {
  key: string;
  header: ReactNode;                     // 可传 ReactNode（如带帮助按钮的表头）
  render: (row: Row) => ReactNode;
  className?: string;
}

interface SimpleTableProps<Row> {
  columns: SimpleColumn<Row>[];
  rows: Row[];
  rowKey: (row: Row, index: number) => string | number;
  onRowClick?: (row: Row) => void;
  loading?: boolean;
  emptyText?: string;                    // 默认「暂无数据」
  dense?: boolean;                       // 详情页紧凑态
  tableClassName?: string;               // 如 min-w-[760px]
  rowClassName?: (row: Row, index: number) => string; // 如已删除角色行高亮
}
```

配套共享组件：`StatusBadge`（状态着色）、`InfoCard`/`InfoRow`（详情页信息卡）、`ConfirmDialog`（二次确认，tone: danger/success/emerald/warning/primary）、`BanFlowDialogs` + `useBanFlow`（封禁表单→二次确认双 Dialog 状态机）、`useRowSelection`（表格勾选）。

### 7.3 侧边栏导航（按 GM 等级动态渲染）

```tsx
// src/shared/components/Sidebar.tsx

import { usePermission } from '@/shared/hooks/usePermission';
import { NavLink } from 'react-router-dom';
import {
  LayoutDashboard, Users, UserCircle, Receipt,
  Shield, ScrollText, LogOut,
} from 'lucide-react';

const menuItems = [
  { path: '/', label: 'Dashboard', icon: LayoutDashboard, minGmLevel: 1 },
  { path: '/accounts', label: '账号管理', icon: Users, minGmLevel: 3 },
  { path: '/characters', label: '角色管理', icon: UserCircle, minGmLevel: 1 },
  { path: '/transactions', label: '交易记录', icon: Receipt, minGmLevel: 1 },
  { path: '/gm-tools', label: 'GM 工具', icon: Shield, minGmLevel: 2 },
  { path: '/audit-logs', label: '日志审计', icon: ScrollText, minGmLevel: 2 },
];

export function Sidebar() {
  const { hasGmLevel } = usePermission();
  const { logout } = useAuth();

  return (
    <nav className="flex flex-col h-full bg-card border-r border-border">
      <div className="p-4 border-b border-border">
        <h1 className="text-lg font-bold text-primary">ACM</h1>

            <NavLink
              key={item.path}
              to={item.path}
              className={({ isActive }) =>
                `flex items-center gap-3 px-4 py-2 text-sm transition-colors ${
                  isActive
                    ? 'bg-primary/10 text-primary'
                    : 'text-muted-foreground hover:bg-accent hover:text-accent-foreground'
                }`

              <item.icon className="w-4 h-4" />

            </NavLink>
          ))}
      </div>

        <button
          onClick={logout}
          className="flex items-center gap-3 w-full px-4 py-2 text-sm text-muted-foreground hover:text-destructive transition-colors"
        >
          <LogOut className="w-4 h-4" />
          退出登录
        </button>
      </div>
    </nav>
  );
}
```
