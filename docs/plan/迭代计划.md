# acore-manager 迭代计划

## 迭代一：基础框架搭建

**目标**：搭建前后端基础框架，建立数据库连接与项目骨架。

**交付物**：
- 后端服务可启动，能连接 auth/characters/world 三个数据库
- 前端工程可构建，路由系统与布局框架就绪
- 统一的 API 响应格式与错误处理机制
- 本地开发环境可通过 Docker Compose 一键启动

---

## 迭代二：认证与系统总览

**目标**：实现用户登录与 Dashboard 首页。

**交付物**：
- 登录页面（兼容移动端）
- JWT 鉴权与 GM 等级守卫
- Dashboard 展示：在线玩家数、今日新增/活跃账号、服务器运行时长、最近事件

---

## 迭代三：账号管理

**目标**：实现账号的查询与封禁管理能力。

**交付物**：
- 账号列表（分页、搜索）
- 账号详情（基本信息、角色列表、封禁记录、登录历史）
- 封禁/解封功能
- IP 封禁管理

---

## 迭代四：部署与优化

**目标**：完成生产部署与性能优化。

**交付物**：
- Docker 镜像构建与优化
- CI/CD 流水线
- 腾讯云 SCF 部署
- 移动端体验优化
- 权限体系简化（如需要，将 4 级管理员合并为 2 级）

---

## 迭代五：交易记录

**目标**：实现金币交易记录的查询能力。

**交付物**：
- 交易记录列表（支持角色名、对象、时间范围、交易类型、金币数额筛选）
- 指定角色的交易记录详情

---

## 迭代六：GM 工具

**目标**：实现 GM 日常操作工具集。

**交付物**：
- 在线 GM 面板
- 广播消息发送
- 坐骑/宠物发放
- 称号管理
- 查找玩家

---

## 迭代七：日志审计

**目标**：实现操作日志的记录与查询。

**交付物**：
- GM 操作日志（按时间/操作人/类型筛选）
- 后台登录日志
- GM 命令执行日志

---

## 迭代八：多游戏区支持

**目标**：支持管理多个游戏区（realm）。

**交付物**：
- 多 realm 数据库配置
- 区服切换能力
- 各区服数据独立展示

---

## 迭代九：角色管理

**目标**：实现角色的查询与基础操作。

**交付物**：
- 角色列表（分页、搜索）
- 角色详情（属性、装备、背包、技能、任务、声望、竞技场）
- 角色操作入口（改名、传送、卡死恢复等）
