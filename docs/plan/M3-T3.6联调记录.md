## 联调发现并修复的缺陷

1. **maxTokens 截断（根因）**：`model-factory` 对库配置缺省 maxTokens 不设兜底，kimi 提供方默认
   ~4k 完成 token，巡检报告 JSON 8.7k 字符被腰斩，extractJson 对不平衡 JSON 必然失败且追问轮
   在旧上下文下回散文。修复：`maxTokens: cfg.maxTokens ?? 8192` + 追问 prompt 强制"重新输出完整
   JSON 文档（从 { 到 }，无 markdown 围栏，不续写上文）"。
2. **thread_id 跨运行复用**：`inspection-{realm}-{date}-{attempt}` 不含运行戳，重跑时模型在
   checkpointer 旧上下文里直接重放结论（实测零工具调用落库），日志变化会保留陈旧结论，且同线程
   上下文随重跑膨胀推高 prompt 成本。修复：thread_id 追加 `Date.now()` 运行级唯一戳。
   注意：旧线程 checkpoint 仍留存于 PG（checkpoint_blobs/checkpoints），清理策略归 M4 观察项。
3. **aura-rules 缺十字军光环条目**：`MOVEMENT_AURA_RULES` 原无骑乘移速来源，已回填
   `{34859, 32223} → ['speed']` 并补单测（待校准注同步更新）。
