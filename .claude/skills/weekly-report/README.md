# Weekly Report Skill

团队周报生成技能，自动从markdown文件生成美观的HTML周报页面。

## 🚀 功能特性

- ✅ **智能内容分析**：支持自由文本、结构化、标签化多种格式
- 📊 **自动统计生成**：任务数、项目数、重点事项自动提取
- ⚡ **智能要点归纳**：自动合并相似任务，每人工作要点不超过5个
- 🎨 **移动端友好设计**：750px宽度，适配微信长图，支持一键保存为图片
- 🌈 **8种主题随机切换**：每周根据周数哈希自动选择不同风格
- 💬 **24种随机激励语**：头部横幅+页脚共24种有温度的鼓励
- 🏅 **成员激励徽章**：随机12种称号标签（高效达人、拼命三郎等）
- 🔧 **一键生成**：简单的自然语言调用

## 📖 使用方法

### 方式1：在Claude Code对话中使用（推荐）

**直接描述需求**：
```
请生成周报，文件是 inputs/2026-W01.md
```

**明确指定skill**：
```
请使用 weekly-report skill 处理 inputs/2026-W01.md
```

### 方式2：使用Command快捷调用

在Claude Code对话中输入：
```
/weekly-report inputs/2026-W01.md
```

### 方式3：使用Claude CLI（终端）

```bash
# 通过Claude CLI调用
claude "请生成 inputs/2026-W01.md 的周报"
```

## ⚠️ 重要说明

**Command不能在终端直接执行**：
- ❌ 错误：在终端中执行 `/weekly-report inputs/2026-W01.md`
- ✅ 正确：在Claude Code对话中输入 `/weekly-report inputs/2026-W01.md`
- ✅ 正确：在终端中执行 `claude "生成 inputs/2026-W01.md 的周报"`

## 📝 输入格式

### 格式1：自由文本（推荐）

```markdown
## 张三

本周完成了用户登录功能开发。
修复了3个线上bug。
下周计划开始支付模块开发。
有个风险点是依赖接口还没就绪。
```

### 格式2：结构化

```markdown
## 李四

【本周完成】
- 编写单元测试用例
- 修复3个bug

【下周计划】
- 集成测试

【风险】
- 测试环境不稳定
```

### 格式3：标签化

```markdown
## 王五

#完成 API文档编写
#计划 编写使用手册
#问题 接口未就绪
```

## 💡 特色功能

### 智能要点归纳

- 每个成员的工作要点自动合并，不超过5个
- 相似任务归类（如：页面+后端 → 功能全栈开发）
- 层级化表达（如：修复多个bug（A、B等））
- 突出成果而非过程

### 数据表述凸显

- 尽量保留原始周报中的数据（数量、百分比、时间、规模等）
- 数量前置：如"修复3个bug"而非"修复多个bug（3个）"
- 保留精确度：不将"50个"改为"多个"或"大量"
- 合并同类型数据：如"完成2个功能提交、4个代码重构提交"

### 智能徽章匹配

- **24种徽章库**：涵盖效率、质量、技术、协作、创造、成就、攻坚、勤奋等多个维度
- **智能匹配**：AI根据成员工作内容自动选择最匹配的徽章
- **去重机制**：徽章一旦被使用，其他成员不能再使用
- **匹配示例**：
  - "优化代码、重构" → 🦾 代码狂人
  - "联调对接、协作" → 🌈 协作天使
  - "修复bug、排查问题" → 🌋 问题终结者
  - "创新方案、改进建议" → 💡 点子王
  - "ui设计、交互优化" → 🎨 艺术家

### 一键保存为图片

- 内置html2canvas库，无需任何安装
- 高清2倍像素密度输出
- 支持Chrome、Safari、Firefox、微信/QQ浏览器
- 自动生成带周数和日期的文件名（如：周报_第3周_20240121.png）
- 每周自动切换主题和激励语
