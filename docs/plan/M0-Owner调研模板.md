> 用途：为迭代十 AI 诊断的**误报防控（需求 3.5）**提供初始配置数据。
> 三张表填写后交给开发，分别落入误报引擎的配置与规则文件（T2.7 aura-rules.ts 等）。
> 凭运营经验填写即可，后续可在后台持续维护，无需一次填全。

## 填写说明

- 地图 ID 可在游戏内 `.go xyz` 或 world 库 `map` 表核对；Spell ID 可在 `spell_dbc` 或 wowhead 核对
- 不确定的条目先标注"待确认"，开发侧会与日志抽样交叉核对
- 本模板填写结果不直接入库，由开发转译为配置；误报白名单的运行时维护走后台 UI（ai_anticheat_exemption）
